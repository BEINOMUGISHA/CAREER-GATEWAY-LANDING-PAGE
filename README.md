# Career Gateway Agency — Landing Page

> Connecting job seekers across Western Uganda with employers who need qualified staff — health, NGO, sales, hospitality, and skilled trades.

## 🚀 Live Demo & Deployment
- **GitHub Pages**: Automatically served from the `main` branch.
- **Vercel**: Deploy with 1-click by importing this repository.

## 🛠️ Built With
- Semantic HTML5
- Custom CSS (Modern typography with Google Fonts `Fraunces`, HSL color palette, responsive design)
- Vanilla JavaScript (Responsive navigation drawer, interactive audience tabs)
